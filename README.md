# Power BI Version History & Version Control Training

## Overview

This training environment was created to demonstrate the evolution of version management capabilities in Power BI and to highlight the differences between Version History and Version Control.

The session covers:

- Power BI Version History
- OneDrive and SharePoint Version History
- Power BI Project (PBIP)
- Git Integration
- Version Control best practices for BI teams
- Team collaboration in Power BI development

## Training Goal

The purpose of this training is to help Power BI developers and analysts understand:

- When Version History is sufficient
- When a true Version Control solution is required
- The advantages of PBIP over traditional PBIX files
- How Git enables collaboration, auditing, branching, and change tracking
- Recommended approaches for individual developers versus BI teams

## Demo Dataset

The included dataset represents a fictional retail company called **HeroVerse Collectibles**, specializing in comic books, action figures, statues, and superhero collectibles from the Marvel and DC universes.

The model contains:

- Customers
- Products
- Branches
- Sales Agents
- Sellers
- Sales Transactions

The dataset was intentionally designed as a Star Schema model to support Power BI demonstrations including:

- Semantic Modeling
- Relationships
- DAX Measures
- KPIs
- Drill Through
- Time Intelligence
- Version Control Scenarios

## Key Takeaway

**Version History helps you recover changes.**

**Version Control helps you manage development.**

Understanding the difference is essential for building scalable, maintainable, and collaborative Power BI solutions.
